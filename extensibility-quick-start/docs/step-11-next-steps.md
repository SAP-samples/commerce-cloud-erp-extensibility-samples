# Step 11: Next Steps

You have completed the extensibility quick start. You extended core commerce capabilities end-to-end — from custom cart validation logic in a commerce serverless function, through synchronous extensions wired to cart extension points, to a storefront customization that surfaces the error in a user-friendly way, observability to monitor and troubleshoot your extensions, and a plugin that bundles everything for reuse across tenants.
